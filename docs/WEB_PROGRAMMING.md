# FTM-500D / FTM-510D 网页写频平台使用指南与注意事项

本中文固件扩展了 **6,358** 个简体中文字形（覆盖 100% GB2312 一级字库与常见地名缺字），其中大量常用简体汉字（如 `亚 频 县 铜 连 盐 滨 迁 桥 镇 锡 苏 门 阴 溧 阳 甪 协` 等）使用了固件专有私有码位或复用了原日文汉字槽位。

官方 PC 软件 **ADMS-16 / ADMS-18 无法正确编码这些中文字符**。如需编辑包含简体中文的存储信道名称并写入电台，请使用配套网页写频平台。

---

## 一、写频网址与环境要求

- **在线写频网址**：**[https://s.dunklive.cn/](https://s.dunklive.cn/)**
- **页签入口**：
  - FTM-500D 用户选择 **`📡 500D信道管理`**
  - FTM-510D 用户选择 **`📡 510D信道管理`**
- **浏览器要求**：
  - 仅支持具备 **Web Serial API** 的桌面浏览器（推荐 **Google Chrome** 或 **Microsoft Edge** 最新桌面版）。
  - **手机/平板浏览器及 Firefox / Safari 不支持 Web Serial 串口直连**。
  - 若浏览器安装了串口调试/拦截类扩展插件导致握手异常，请改用 **Chrome 无痕窗口（隐身模式）** 访问。

---

## 二、硬件连接与串口参数

- **写频线缆**：使用 Yaesu 原装 **`SCU-20`** USB 编程线（或兼容 **`SCU-58`** / 10 针 mini-DIN 转串口线），连接至电台主机背后 **10 针 `DATA` 接口**与电脑 USB 接口。
  - 若使用 Windows，请确保系统已安装对应的串口芯片驱动（可在设备管理器中看到独立 `COMx` 端口号）。
- **串口参数**：整机克隆（CLONE）模式固定为 **`38400 bps` / `8N1`**，无需在网页额外调整波特率。
- **端口占用排查**：使用网页写频前，务必**完全关闭** `ADMS-16 / ADMS-18`、串口调试助手或其他占用该 `COM` 口的软件。

---

## 三、标准写频流程（强烈建议每次先读后写）

### 第一步：连接并读取电台当前整机映像（务必先备份）

1. 打开 **[https://s.dunklive.cn/](https://s.dunklive.cn/)**，切换到 **`500D信道管理`** 或 **`510D信道管理`**。
2. 在网页点击**读取整机映像**，在弹出的浏览器串口授权窗中选择电台对应的 `COM` 口并确认连接。
3. **在电台操作**：
   - 长按 **`[F-MENU]`** 进入设置菜单。
   - 找到 **第 119 项**（中文菜单：`向外发送` / 英文菜单：`This → Other`，即 `CLONE` 克隆发送）。
   - 按下旋钮进入确认，看到 **`OK`** 后按下旋钮开始向电脑发送。
4. 等待网页进度条读满 **768/768 帧**，读回数据会自动保存在网页本地版本槽位中。
5. **建议立刻点击【导出网页备份】**，将读取出来的原始备份保存一份到本地硬盘，避免意外写入失误无法恢复。

---

### 第二步：编辑信道参数与中文名称

- 可直接在网页表格中编辑各频道的频率、频差、亚音（CTCSS/DCS）、功率、工作模式、DG-ID 及信道名称（可直接输入简体中文、英文或数字）。
- **字符与长度限制说明**：
  1. **长度上限**：单个频道名称的硬件存储槽严格为 **16 字节**，即**最多输入 8 个中文汉字**（每个汉字占 2 字节 / 2 列宽）或 16 个半角 ASCII 字符；超出部分在写入时将被截断。
  2. **字库覆盖校验**：网页写频端已集成与本固件完全一致的 **6,358 字映射表**（[`docs/FONT_CODE_TABLE.tsv`](FONT_CODE_TABLE.tsv)，版本 `map500d-v2-E0EA3399E8371E23`）。支持 GB2312 一级字库 `3,755/3,755` 及常用地名汉字；若误输入了未收录的极生僻字/GBK 扩展字，网页会明确提示未收录字符并在写入时安全兼容处理，**不会写入损坏字节**。
  3. **语言选项切换**：在写入配置栏可将电台写入后的菜单语言状态同步设为 **`中文`** 或 **`英文`**。

---

### 第三步：整机克隆回写到电台

1. **在电台操作进入接收模式**：
   - 长按 **`[F-MENU]`** 进入设置菜单，找到 **第 120 项**（中文菜单：`从外接收` / 英文菜单：`Other → This`）。
   - 按下旋钮确认，选中 **`OK`** 并按下旋钮，使电台屏幕显示 **`WAITING`** 等待接收状态。
2. **在网页发起写入**：
   - 点击网页中的**写入整机映像**，在引导确认弹窗点击**开始写入**（如果在电脑端先点了开始写入，系统会在 15 秒内持续自动重发探测，趁此时在电台按 `OK` 进入 `WAITING` 同样可顺利握手）。
   - 保持连接直到 **768/768 帧全部传输与 ACK 确认完成**，电台屏幕恢复正常重启或完成写入界面。

---

## 四、重要注意事项（必读）

1. **为什么不能用 `ADMS-16 / ADMS-18` 直接写中文地名？**
   - 像 `铜 连 盐 滨 迁 桥 镇 锡 苏 门 阴 溧 阳 甪 协` 等汉字全都不在日本 JIS X 0208 字库里；用官方 ADMS 软件或普通 Shift-JIS 工具直接输入汉字，下发的是错误编码字节，上机屏幕必然显示异常或变问号。只有通过 [s.dunklive.cn](https://s.dunklive.cn/) 按固件码表编码写入，才能在电台屏幕上正确显示简体汉字。
2. **整机克隆协议特性与断线风险**：
   - FTM-500D 与 FTM-510D 的 ADMS 协议均强制传输 **98,304 字节（768 帧 × 131 字节）整机映像**，不支持只写单个频道。
   - **写入过程中严禁拔掉数据线、关闭浏览器标签页、让电脑进入休眠或给电台断电**。写前务必留好电脑导出备份 + 电台 SD 卡全量备份。
3. **连续中文名称回读提示**：
   - 原版 ADMS 协议底层解码逻辑在部分连续全角字节的宽度位图处理上存在官方局限。若重新从电台回读刚刚写入中文名的映像，本机浏览器会结合缓存与原始字节正常显示；如更换电脑重新读回时发现个别中文字符回读展示受原版解码规则限制，属于官方协议限制，不影响电台自身屏幕正常显示。
4. **C4FM / APRS 等空中转发场景兼容性**：
   - 私有码位及复用字槽仅用于本机中文固件 UI 与本地信道名显示；通过 C4FM/APRS 等协议发送给未刷中文固件的其他友台时，对方非中文机器仍会按其原厂 JIS 字库解释非 ASCII 字节，跨台互通呼号与信标内容建议保留英文/ASCII。
