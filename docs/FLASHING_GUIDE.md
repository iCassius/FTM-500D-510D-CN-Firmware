# FTM-500D / FTM-510D 刷机指南与版本自查说明

> [!WARNING]
> **刷机有风险，操作前请完整通读本指南！**
> FTM-500D / FTM-510D 的 SUB 固件内含重启与 SD/FAT 刷写引导逻辑，静态未见独立第三方救砖引导。**刷写过程中严禁断电、拔卡或重置**；务必使用稳压直流电源供电，并提前备份整机数据。

---

## 一、刷机前务必核对自己的硬件版本（极其重要）

不同销售地区的 Yaesu 电台主板搭载对应地区的 Bootloader 与 `MAIN` 校验标签（`MA0` / `MA1` / `MA2` / `MA3`）：

| 型号 | 地区代号 | SFL Header Tag | 当前真机实测情况 |
|---|---|---|---|
| **FTM-500D** | 国行 **CHN** | `MA3` | **已真机实测通过** |
| **FTM-500D** | 日版 **JPN** | `MA0` | **已真机实测通过** |
| **FTM-500D** | 美版 **USA** | `MA2` | 静态与结构校验通过，待美版真机反馈 |
| **FTM-510D** | 日版 **JPN** | `MA0` | **已真机实测通过** |
| **FTM-510D** | 国际版 **EXP** | `MA1` | **已真机实测通过（多位国内购买“国行”的 510D 用户实测本机实为 EXP 版）** |
| **FTM-510D** | 国行 **CHN** | `MA3` | 静态与安全审计通过，待 `CHN_MA3` 原生硬件反馈 |
| **FTM-510D** | 美版 **USA** | `MA2` | 静态与安全审计通过，待美版真机反馈 |

### 如何确认自己的真实硬件版本？

1. **特别提示 FTM-510D 国内用户**：
   - 已收到多位国内购买“国行”机器的 510D 机友反馈：机身/购买渠道按国行购入，但机内实际是 **EXP（国际版）** 硬件。
   - **千万不要直接按“中文=CHN”想当然选择 `CHN_MA3`**。
2. **排查建议**：
   - 核对购机时电台原厂默认发射/接收频段规则、说明书后缀（`E`=EXP、`R`=USA、`D`=JPN）或官网下载对应地区原版固件包测试。
   - Bootloader 自身会在读取 SD 卡根目录的 `FTM500D/` 或 `FTM510D/` 时校验唯一的 `MAIN` 文件头 Tag。如果选错了地区包（例如 `EXP` 机器放了 `CHN_MA3`），Bootloader 升级界面通常会报错拒绝刷新（`sfl ng` 类提示）；**遇到报错立即关机换对应地区目录（如改用 `FTM-510D/EXP_MA1/`），不要反复强行操作**。

## 二、准备工作

1. **整机配置备份（必须）**：
   - 将一张正常使用的 microSD 卡插入电台（建议预先格式化为 FAT32）。
   - 进入电台 Setup Menu **`BACKUP`（#107） -> `WRITE TO SD` -> `ALL`**，保存整机内存与设定备份文件到电脑留存。
2. **下载并核对固件文件**：
   - 根据自己的型号与地区下载对应目录，或从 GitHub [Releases](../../releases) 下载对应 ZIP 包。
   - 解压后核对目录内是否**严格只有 3 个 `.SFL` 文件**：
     - **FTM-500D**：`FTM500D/` 下仅含 `FTM-500D_MAIN_<地区>_V0120.SFL`、`FTM-500D_SUB_V0120.SFL`、`C4FM-DSP_V0720.SFL`。
     - **FTM-510D**：`FTM510D/` 下仅含 `FTM-510D_MAIN_<地区>_V0110.SFL`、`FTM-510D_SUB_V0110.SFL`、`C4FM-DSP_V0720.SFL`。
   - **严禁把多个地区的 `MAIN` 文件同时放在同一个 `/FTM500D/` 或 `/FTM510D/` 文件夹内！**
   - 有条件建议执行校验：`sha256sum -c MANIFEST_SHA256.txt`。
3. **格式化刷机用 microSD 卡并拷贝**：
   - 先用电台 Setup Menu **`FORMAT`（#109）** 将 microSD 卡格式化（推荐 32GB 及以下优质卡）。
   - 拔卡插电脑，把 **`FTM500D/`**（500D 机型）或 **`FTM510D/`**（510D 机型）整个文件夹放到 microSD 卡**最顶层根目录**（例如 `E:\FTM500D\...`）。

## 三、上机刷写步骤

1. **插入 microSD 卡**：电台关机状态下插好已拷贝固件的 microSD 卡。
2. **进入固件更新模式（Firmware Update）**：
   - 按住前面板 **`[DISP]`** 键不放，再短按 **`[POWER]`** 电源键开机，松手后屏幕进入 `Firmware Update` 菜单。
3. **检查待升级模块勾选状态**：
   - 确认 **`MAIN`** 和 **`SUB`** 均处于勾选状态（实心圆点 **`●`**）；如原机 `C4FM-DSP` 版本低于 `07.20`，可同时勾选 `DSP`（若原机已是 `07.20`，保持默认或一并勾选均可）。
   - **核心红线：`MAIN` 与 `SUB` 必须同时匹配刷写！**
     - 如果只刷 `MAIN` 不刷 `SUB`（或反之），中文私有码位（`0x222F+`）会显示空白方块或乱码字形。
4. **执行刷写与等待完成**：
   - 按屏幕下方提示按压对应按键/旋钮开始更新，屏幕会依次写入各区。
   - **全程保持稳压电源供电，绝不可触碰电源开关、拔插面板线或微动 SD 卡**。
   - 等待屏幕明确提示 **`Updating.. OK`**（或对应完成提示）后，按提示安全关机/断电重启。

## 四、刷写后初始化与开启中文

1. **核对版本**：开机后进入 Setup Menu **`SOFTWARE VERSION`（第 126 项）** 查看 `Main` / `Sub` / `DSP` 是否与刷入版本一致。
2. **FTM-510D 恢复出厂设置（推荐）**：
   - 510D 刷写后（或发现语言菜单未显现时），请执行一次 Setup Menu **`FACTORY RESET`（第 128 项 / 恢复出厂设置）**，确保 EEPROM 地区状态与解锁的语言开关完全同步，再通过此前写入或网页备份还原频道数据。
3. **切换简体中文界面**：
   - 进入 Setup Menu **`LANGUAGE`（第 127 项 / 语言设置）**。
   - 将选项从 `ENGLISH:英文` 切换为 **`CHINESE:中文`** 即可。切换结果会写入 EEPROM，断电重启依然保持中文；需要纯英文面板时可随时切回 `ENGLISH:英文`。

## 五、常见问题排查

- **开机或进 Bootloader 提示 `SFL NG` / 找不到固件文件**：
  1. 检查卡根路径是否为 `microSD:/FTM500D/*.SFL` 或 `microSD:/FTM510D/*.SFL`（切勿多套一层文件夹，如 `FTM500D/FTM500D/`）。
  2. 检查文件夹内是否只放了**唯一一份**对应地区的 `MAIN` 文件。
  3. 对 **510D 国内购入机**，若 `CHN_MA3` 无法识别，请换用 **`EXP_MA1`** 包重试！
- **中文菜单能进，但部分汉字变成空白或日文/错字**：
  - 未同时升级配套版本的 **`SUB`** 固件。请重新进入 `[DISP] + [POWER]` 确保 **`MAIN` 和 `SUB` 同时勾中为 `●`** 完整重刷一次。
- **使用官方 ADMS-16 / ADMS-18 写入频道名称后屏幕显示乱码**：
  - 官方软件仅按日文 Shift-JIS 编码，请务必改用 **[https://s.dunklive.cn/](https://s.dunklive.cn/)** 进行中文信道管理与克隆写入（详见 [网页写频说明](WEB_PROGRAMMING.md)）。
