# Yaesu FTM-500D / FTM-510D 简体中文双语固件与网页写频发布库

本仓库仅发布 **Yaesu FTM-500D (`V01.20`)** 与 **FTM-510D (`V01.10`)** 各硬件地区版本可直接上机刷写的简体中英文双语固件二进制（`.SFL`）、SHA-256 校验清单、刷机指南与网页写频说明。

> [!CAUTION]
> **刷机前务必确认自己的电台硬件版本与地区代码！**
> 特别是 **FTM-510D 国内购入机型：多位“国行”用户反馈实机原厂实际为 `EXP`（国际版 / `MA1`）而非 `CHN`（`MA3`）**。刷入前请先核对自身机器版本（详见下方说明与 [刷机详细指南](docs/FLASHING_GUIDE.md)），切勿盲目混刷其他地区包。

---

## 核心特性

- **真中英双语自由切换**：保留原版完整英文界面（EN），将日文菜单槽（JA）全量替换为简体中文；内置 Boot 菜单解锁补丁，可在设置菜单 **`LANGUAGE`（语言设置）** 中随时切换 **`ENGLISH:英文`** / **`CHINESE:中文`** 并断电记忆。
- **全量简体中文字库（6,358 字模，通格像素黑体 14px）**：
  - 完整替换固件内全部可替换日文专用汉字，覆盖 **100% GB2312 一级字库（3,755/3,755）**、**2,582/3,008 GB2312 二级字库**及常用地名缺字（含 `铜 连 盐 滨 迁 桥 镇 锡 苏 门 阴 溧 阳 甪 协` 等），完整码表见 [`docs/FONT_CODE_TABLE.tsv`](docs/FONT_CODE_TABLE.tsv)。
  - 完整保留 JIS `ku 1..15` 全部标点、单位与 UI 符号，并保留常用英文快捷键与协议字段不乱码。
- **配套网页写频支持中文信道名**：支持通过桌面浏览器访问 **[https://s.dunklive.cn/](https://s.dunklive.cn/)** 直连串口读取与写入中文信道名（已同步 6,358 字码表）。
- **严格校验**：全部产物均已重算 Renesas RX 硬件尾 CRC-32 与 SFL 容器带盐 CRC-32，可通过 `sha256sum` 校验。

## 刷机前必读：如何确认自己电台的硬件版本

1. **查看机身标签、外包装与原厂购买渠道信息**：
   - `FTM-500DR`（USA）、`FTM-500DE`（EXP/EU）、`FTM-500D` 日版（JPN）或中国国内版（CHN）。
   - `FTM-510DR/DE/D` 同理；但**国内部分渠道标注“国行”的 FTM-510D 实际主板出厂是 `EXP` 国际版**，不能只看中文说明书或包装贴纸猜测。
2. **用网页写频或电台菜单辅助核对（最安全）**：
   - 进入电台设置菜单查看 `SOFTWARE VERSION` 确认当前 `MAIN / SUB / DSP` 版本号。
   - **通过 Bootloader 实测识别是最直观的把关方式**：电台 Firmware Update Bootloader 会严格校验 SD 卡内唯一一份 `MAIN` 文件的 576B 外壳 Tag（`MA0` / `MA1` / `MA2` / `MA3`）。如果版本不匹配，升级界面不会接受错误地区的 `MAIN`（通常会报 SFL 不匹配提示而拒绝刷写）。
   - 例如 **FTM-510D 国内机器**：若怀疑自己可能是 `EXP` 或 `CHN`，建议先到 [GitHub Releases](../../releases) 下载对应版本的官方结构封装包，放到 SD 卡试进 `[DISP] + [POWER]` 查看机器识别情况，**确认能正常识别并列出版本后再刷写，且切记同时同步刷写 MAIN + SUB**。
3. **刷机前务必备份整机配置**：
   - 进入电台菜单 `BACKUP -> WRITE TO SD -> ALL` 将整机配置与信道备份到 microSD 卡。

详细图文级文字步骤与排障说明见：**[刷机详细说明（docs/FLASHING_GUIDE.md）](docs/FLASHING_GUIDE.md)**。

## 快速刷机步骤摘要

1. **备份与格卡**：先备份整机配置到 SD 卡，再用另一张或清空后的 microSD 卡在电台执行 `FORMAT` 格式化为 FAT/FAT32。
2. **拷贝对应地区目录**：
   - **500D**：下载对应版本目录（如 `FTM-500D/CHN/`）内的整个 **`FTM500D/`** 文件夹，复制到 microSD 卡根目录（卡内路径为 `microSD:/FTM500D/*.SFL`，**仅保留 3 个 `.SFL` 文件**）。
   - **510D**：下载对应版本目录（如 `FTM-510D/EXP_MA1/` 或 `FTM-510D/JPN_MA0/`）内的整个 **`FTM510D/`** 文件夹，复制到 microSD 卡根目录（卡内路径为 `microSD:/FTM510D/*.SFL`，**仅保留 3 个 `.SFL` 文件**）。
   - **推荐直接前往本仓库 [Releases 页面](../../releases)** 下载对应硬件版本的 `.zip` 压缩包，解压后即可直接将 `FTM500D` 或 `FTM510D` 文件夹拖进 SD 卡根目录。
3. **进入升级模式**：关机状态下按住 **`[DISP]`** 键不放，再按下 **`[POWER]`** 键开机，进入 `Firmware Update` 界面。
4. **勾选并刷写**：旋转 DIAL 确认 **`MAIN`** 与 **`SUB`** 均标记为 **`●`**（若原机 `C4FM-DSP` 版本低于 `07.20` 可一并勾选；**`MAIN` 与 `SUB` 必须成对刷写**，不能只刷其一），按提示启动更新并等待 **`Updating.. OK`**。**期间严禁断电！**
5. **切换中文界面**：
   - 重启后在设置菜单确认版本，**510D 建议先做一次 `FACTORY RESET`（恢复出厂设置）** 让新增语言菜单与地区状态完成初始化。
   - 进入设置菜单 **`LANGUAGE`**（第 127 项），选择 **`CHINESE:中文`** 即可。

## 网页写频（中文信道名编辑与整机克隆）

- **在线写频网站**：**[https://s.dunklive.cn/](https://s.dunklive.cn/)**（请使用桌面端 **Chrome** 或 **Edge** 浏览器访问）
- **支持页签**：页面顶部 **`📡 500D信道管理`** / **`📡 510D信道管理`**
- **核心注意事项**：
  1. 必须使用该网页平台（或按 [`docs/FONT_CODE_TABLE.tsv`](docs/FONT_CODE_TABLE.tsv) 编码）写入中文信道名；**官方 `ADMS-16 / ADMS-18` PC 软件只认日文 Shift-JIS，用原厂软件直接打汉字会导致乱码或显示为 `?`**。
  2. 连接电台背部 10 针 `DATA` 口（如 `SCU-20` 编程线），串口波特率固定 **`38400 bps (8N1)`**。
  3. 写频前务必先执行 **`[119 This → Other]`（向外发送）** 读取整机当前映像并点击**导出网页备份**。
  4. 写入为 **768 帧整机克隆**（不能单频道写入），进入 **`[120 Other → This]`（从外接收） -> `OK`** 屏幕显示 `WAITING` 后再在网页发起写入。

完整写频操作流程、避坑说明与限制详见：**[网页写频说明与注意事项（docs/WEB_PROGRAMMING.md）](docs/WEB_PROGRAMMING.md)**。
